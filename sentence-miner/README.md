# Sentence Miner（プロトタイプ）

日本語話者の英語学習者向け、AIネイティブなセンテンスマイニング（用例つき単語カード生成）Webツールの最小試作。

## コア体験（一本道）

1. 英文を貼る or 記事URLを貼る
2. レベル（CEFR / TOEIC帯）を選ぶ
3. AIが「そのレベルで覚える価値のある語」を抽出
4. 各語につき カード生成（表＝元の文／裏＝文脈に沿った日本語の意味＋自然な例文）
5. 画面で確認・不要なカードを削除
6. **Anki取り込み用CSVで書き出し**

## 実装済みのMVP仕様

- ソースは「テキスト貼り付け」＋「記事URL」の2つ（URLは `r.jina.ai` リーダー経由で本文取得）
- レベル指定（A2〜C1 / TOEIC帯）で、それ未満の易しい語は除外
- 「もう知ってる単語リスト」で重複除外
- カードは「文ごと」が既定、単語単体カードは任意オプション
- 1回の最大語数を指定可能（無料/有料の線引きの土台）
- Anki取り込み用CSV書き出し（`#separator:Comma` / `#html:true` ディレクティブ付き、Front/Back の2フィールド）

## 動かし方

1. ブラウザでこの `index.html` を開くだけ（ビルド不要）。
   - ローカルファイルで動きます。CDN（Tailwind）に到達できれば見た目も整います。
2. 右上の「APIキー設定」で Anthropic の API キーを入力。
   - キーはブラウザの sessionStorage にのみ保存（タブを閉じると消える）。サーバーには送りません。
3. 英文を貼って「カードを生成」。

### 技術メモ

- AI抽出は Claude Messages API（`claude-sonnet-4-6`）をブラウザから直接呼び出し。
  - `anthropic-dangerous-direct-browser-access: true` ヘッダで直接アクセス。
  - 構造化出力（`output_config.format` の JSON Schema）で、パース可能なカード配列を保証。
  - より高精度が必要なら `index.html` の `MODEL` を `claude-opus-4-8` に変更。
- 純フロントエンドのため、任意URLの直接 `fetch` は CORS で弾かれる。記事取得は無料リーダー
  `https://r.jina.ai/<url>` を経由して回避している。
